# Plan errata

Each entry names the plan section it amends. Decisions themselves change only through `docs/decisions.md`.

| E-15 | §3.1 (network: names), WP1.1 (lab names on the Legion) | "one edit of the Legion's `hosts` file, which WSL2 copies when it starts, so run `wsl --shutdown` once afterwards" | The Legion's `/etc/wsl.conf` sets `[network] generateHosts = false` (it keeps hand-made `/etc/hosts` entries for other work), so WSL2 never copies the Windows hosts file. `infra/lab/install-hosts.sh` writes the same marked block of `infra/lab/lab-hosts.txt` into **both** the Windows hosts file (UAC) and WSL2's `/etc/hosts` (`sudo`), replacing only the `# BEGIN kairos-lab` … `# END kairos-lab` block and keeping a `.kairos-backup` copy of each; no `wsl --shutdown` is needed. `lab-hosts.txt` stays the single list of lab names | WP0.1 |
